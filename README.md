# Учебный репозиторий для практики GitHub

### СОСТАВ КОМАНДЫ: Павлова Татьяна, Мошков Кирилл, Никитенко Мария, Красюк Надежда

## Правила для команды:
1. **Капитан** создает репозиторий с файлами main.py, Issues.txt и README.md и добавляет команду в `Settings -> Collaborators`.
2. **Все** клонируют репозиторий капитана и ОДНОВРЕМЕННО вписывают информацию о себе.
3. Разрешаем конфликт слияния (`Merge Conflict`) при пуше.
4. Разбираем задачи из **Issues.txt** в репозитории капитана. Каждый выполняет по одной задаче. Если команде менее 5 человек, то оставшиеся задачи распределяются на усмотрение капитана.
5. В файле **Issues.txt** напротив выбранной вами задачи написать свои ФИО
6. Любые исправления кода — строго через отдельную ветку (`git switch -c feature/...`) и **Pull Request**.
